    SIP UDP indisponível no navegador

    A conexão SIP sobre UDP só funciona no app desktop (Electron), pois o navegador não permite abrir sockets UDP. Abra o softphone com npm run desktop para usar esta aba.

    Conexão SIP UDP (cliente/servidor)

    Esta aba trata apenas sinalização SIP (REGISTER, OPTIONS, MESSAGE e respostas como servidor). Sem áudio RTP — para chamadas com voz use a aba WebRTC.
